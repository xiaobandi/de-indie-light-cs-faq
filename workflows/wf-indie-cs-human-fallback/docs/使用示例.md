---

## 示例一 · 标准用法（真实运行）

```bash
python3 ../../tools/handoff_triage.py --file examples/input/chat.txt
```

**真实输出**：

```console
处置建议：立即升级（P0）　SLA：5 分钟内人工介入
  [升级] 投诉, 举报, 12315, 诈骗
  [需人工] 退款

交接摘要：用户诉求：我要投诉！你们这是诈骗，再不退款我就12315举报，已经截图了…（命中关键词：投诉/举报/12315/诈骗/退款）
```

> 命中投诉威胁关键词 → 判定最高优先级并给出 SLA，直接进人工队列

> **注意**：涉及人身安全、监管投诉、法律威胁的会话**必须**走人工，不允许自动回复收尾。

---

## 示例二 · 用你自己的材料

```bash
python3 ../../tools/handoff_triage.py --file /path/to/your-data/chat.txt
```

把 `examples/input/` 下的文件换成你的真实材料即可；**输入结构不要改**，改了字段名脚本会读不到。

---

## 示例三 · 嵌进自动化链路

```bash
set -e
python3 ../../tools/handoff_triage.py --file examples/input/chat.txt || exit 2   # 非零即阻断
```

脚本是纯函数：文件/stdin 进、stdout 出、退出码表达判定，因此可以被 CI、定时任务或上层工作流直接编排。
