| 触发层 | 关键词 / 显式点名「知识库构建」；触发方式：人工（初次 + 月更） |
| 执行层 | 文档/FAQ/历史工单导入 → 分段向量化 → 测试问答集验收 |
| 产出层 | 测试问答集验收 |
