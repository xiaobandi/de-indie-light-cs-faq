# 工单摘要 · 用户场景

> 场景来自本技能的注册表数据与归属员工定义卡，不是通用模板。

**服务对象**：有付费用户、存在跨时区咨询的产品型开发者

**员工定位**：出海产品的"夜间值班员"：7×24 双语应答，高价值问题秒转人工

**触发时机**：用户提出需求时
